5. list_users_by_columns
   Description : 
    List user records with configurable response levels.

    Behavior:
    - Supports three response levels to control the amount of data returned.
    - Limits the number of returned records.
    - Returns an empty list if no matching records are found.

    Response Levels:
    - basic:
        Returns only the most commonly used fields:
        LoginID, FirstName, LastName, EmailID, Technology

    - necessary:
        Returns additional organizational information:
        LoginID, FirstName, LastName, EmailID,
        ManagerName, ManagerEmail,
        Department, Technology,
        TransitCode, IsActive

    - all:
    Returns every available column from the user record:
        LoginID, FirstName, LastName, EmailID,
        ManagerName, ManagerEmail,
        Department, Technology,
        TransitCode, Reference,
        CreatedDate, UpdatedDate,
        CreatedBy, UpdatedBy,
        IsActive, Comments

    Returns:
    - users: list of user records based on the requested detail level

    
   Input Schema: {'properties': {'response_level': {'default': 'medium', 'enum': ['basic', 'medium', 'all'], 'title': 'Response Level', 'type': 'string'}}, 'title': 'list_users_by_columnsArguments', 'type': 'object'}
